# Dev-collaboration-code-editor

Dev-collaboration-code-editor is a collaborative, real-time code editor designed to let developers code together seamlessly. Multiple users can join a workspace room simultaneously using a unique room ID to edit code, manage files, chat, and sketch design systems in real time.

---

## Features

- **Real-Time Collaboration:** Instant code synchronization across multiple files and folders.
- **User Presence & Indicators:** View active users with online/offline statuses, real-time tooltips, and active selection highlighting.
- **Code Execution:** Run code snippets directly within the workspace environment.
- **File Management:** Create, organize, edit, and delete files or folders, with the option to download the codebase as a zip archive.
- **Extensions:** Built-in real-time group chat, a shared drawing whiteboard for architecture sketching, and an AI-powered assistant.
- **Customizable Editor:** Auto-language detection, syntax highlighting, autocomplete suggestions, and adjustable font configurations.

---

## Tech Stack

### Frontend
- **React** - Component-based user interface architecture
- **TypeScript** - Static typing for robust code quality
- **Tailwind CSS** - Utility-first styling framework
- **React Router** - Single-page application routing

### Backend
- **Node.js** - Server-side JavaScript runtime environment
- **Express.js** - Minimalist web framework for API routing
- **Socket.io** - Bi-directional, low-latency event-based communication layer

### Tooling
- **Git** - Version control system
- **Docker** - Containerization platform for consistent deployments
